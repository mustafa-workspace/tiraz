# Tiraz (طراز)

**A lightning-fast, minimalist Chrome extension designed for web developers to inspect element CSS instantly using a simple `Ctrl + Click` shortcut.**

## ⚡ Features

* **Instant Inspection:** Skip the heavy DevTools panels. Hold `Ctrl` and click any element to see its core CSS properties immediately.
* **Isolated UI (Shadow DOM):** Built with Shadow DOM encapsulation to ensure the extension's styles never conflict with or get affected by the host website's CSS.
* **Visual Targeting:** Instantly highlights the selected element with a clean, non-intrusive dashed outline.
* **One-Click Copy:** Easily copy computed CSS rules directly to your clipboard with a single click.
* **Sleek & Lightweight:** Designed for developers who value performance, speed, and a distraction-free workflow.
